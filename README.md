# Boxer

Jogo de boxe arcade em primeira pessoa, inspirado nos clássicos do Atari 2600 e controlado por movimentos.

## Como jogar

Na tela inicial, toque em **INICIAR LUTA** e permita o acesso à câmera. Fique de frente para o celular, com o rosto e os braços visíveis:

- Mova a cabeça para um dos lados para desviar do golpe do oponente.
- Estenda rapidamente um dos braços, mantendo o punho na altura do ombro, para socar.

A luta usa a câmera frontal e o reconhecimento de pose do Google ML Kit. A arena é vista pelos olhos do jogador, com o oponente à frente e as luvas do jogador no primeiro plano. O reconhecimento está disponível nas versões Android e iOS; a versão Web informa que a câmera com reconhecimento de pose não é compatível.
